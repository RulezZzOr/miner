      Connecting…

      Start with Three Steps

      1. Open Project. Select its folder using the + button at the top.
      2. Select a model and write a task. One agent works directly, a team delegates to workers.
      3. Monitor and approve work. Action suggestions, results, and files are found in this window.

      Native commands run with your permissions. The GUI allows only one task at a time. Files are not saved automatically. Team mode on Qwen does not yet have verified reliable completion; nested separations are not yet implemented.
